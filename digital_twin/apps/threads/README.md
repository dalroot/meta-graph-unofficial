# Threads (Barcelona) Integration Module

This module documents reverse-engineered operations connecting Instagram with Meta Threads (`Barcelona`).

## Reverse-Engineered Operations
- `CrosspostToBarcelonaSettingsQuery`: Fetches user preference for auto-crossposting to Threads.
- `CrossPostingContentCompatibilityConfigV2`: Verifies text length, aspect ratios, and media constraints between Instagram and Threads.
- `CrosspostingUnifiedConfigsQuery`: Unified policy engine across Meta FOA.
