# [Issue] ارتقا و تکمیل سرور MCP اینستاگرام (TwinGraph Model Context Protocol Server)

> **عنوان ایشو:** تکمیل سرور MCP توینگراف: افزودن ابزارهای تعاملی (دایرکت، کامنت، انتشار پست)، فلو لاگین محلی خودکار، و پشتیبانی چنداکانتی  
> **اولویت:** High (CRITICAL)  
> **برچسب‌ها (Labels):** `enhancement`, `mcp`, `ai-agent`, `digital-twin`, `automation`  
> **وضعیت فعلی:** سرور زنده است و در پشته Stdio کار می‌کند (بخش Ghost Mode با ۷ ابزار عملیاتی است).

---

## ۱. خلاصه و کارکرد فعلی سرور (Current State)

سرور MCP پروژه در مسیر [`ts_src/mcp/server.ts`](../ts_src/mcp/server.ts) و با پکیج رسمی `@modelcontextprotocol/sdk` پیاده‌سازی شده و از طریق ترنسپورت بومی **Stdio** (`StdioServerTransport`) با ابزارهای هوش مصنوعی (مثل Cursor، Claude Desktop، و کلاینت‌های پایتون/تایپ‌اسکریپت MCP) ارتباط برقرار می‌کند.

### ابزارهای فعال کنونی (۷ ابزار اختصاصی Ghost Mode):
تمامی این ابزارها **۱۰۰٪ ناشناس، بدون لاگین و بدون کوکی** کار می‌کنند:
1. `ghost_get_profile`: دریافت پروفایل عمومی، تعداد فالوور و بیوگرافی (تست‌شده روی `@instagram` و `@cristiano`)
2. `ghost_get_posts`: استخراج ۱۲ پست اخیر، ریلزها و کاروسل با آمار تعامل
3. `ghost_get_media_metrics`: استخراج دقیق ویو، لایک، سهم اشتراک و ریچ ریلز
4. `ghost_get_comments`: خواندن کامنت‌های لایو پست‌ها بدون سشن
5. `ghost_search`: جستجوی امن کاربران و هشتگ‌ها
6. `ghost_explore_viral`: اسکن ریلزهای پربحث و داغ اکسپلور
7. `ghost_audit_account`: تحلیل عمیق و ممیزی یک پیج رقیب و محاسبه میانگین بازدید

## ۲. مشکلات فعلی و نواقص (Current Limitations & Gaps)

همکار گرامی باید بر روی این ۴ چالش اصلی کار کند:

### ۱) عدم دسترسی ایجنت‌ها به ابزارهای تعاملی (نبود اکشن‌ها در MCP):
- **مشکل:** اگرچه هسته پروژه (`ts_src/twin_graph.ts` و دوقلوهای موبایل/وب) قابلیت‌های تعاملی نظیر ارسال پیام دایرکت، ارسال کامنت، پاسخ به منشن، و آپلود تصویر و ریلز را دارند، اما این متدها در `ts_src/mcp/server.ts` **به عنوان Tool تعریف نشده‌اند**.
- **وظیفه:** باید ابزارهای تعاملی (مشابه ابزارهای Composio مثل `send_direct_message`, `post_media_comment`, `publish_reel`) به لیست ابزارهای MCP اضافه شوند.

### ۲) نبود فرآیند لاگین محلی خودکار (Manual Session Extraction):
- **مشکل:** در حال حاضر کوکی‌ها یا سشن‌ها باید به صورت دستی در `instagram_session.json` قرار گیرند.
- **وظیفه:** پیاده‌سازی یک ابزار/اسکریپت تحت نام `twin_local_login` که با اجرای یک دستور، پنجره لاگین رسمی را باز کند و کوکی‌های `sessionid`, `csrftoken`, `ds_user_id` را خودکار ذخیره کند.

### ۳) عدم مدیریت چنداکانتی (Multi-Account Context):
- **مشکل:** ابزارهای فعلی MCP فرض می‌کنند که تنها با یک سشن پیش‌فرض کار می‌کنند. ایجنت باید بتواند مشخص کند با کدام اکانت (Profile ID یا Username) می‌خواهد پیام بفرستد یا پست بگذارد.

### ۴) ترنسپورت محدود به Stdio (نیاز به HTTP / SSE):
- **مشکل:** سرور فعلی فقط روی ورودی/خروجی استاندارد کنسول (`stdio`) ران می‌شود که برای اتصال به کلاینت‌های راه دور (Remote Agents) مناسب نیست.
- **وظیفه:** اضافه کردن مد `Streamable HTTP / SSE` در کنار `stdio` تا ایجنت‌های تحت شبکه هم بتوانند از این سرور استفاده کنند.
